# DocMind —— 企业级智能知识库助手

一个基于大模型的文档知识库问答产品，支持多格式文档解析、向量检索（RAG）、多轮对话与 Agent 工具调用。

## 功能规划
- [ ] 文档解析（PDF / Word / TXT / Markdown）
- [ ] 向量检索 + 混合检索
- [ ] 大模型生成 + 引用溯源
- [ ] 多轮对话与上下文记忆
- [ ] Agent 工具调用
- [ ] Web 界面
- [ ] Docker 部署
- [ ] 问答质量评测

## 技术栈（规划）
Python · FastAPI · ChromaDB · Streamlit · SQLite · Docker · 大模型 API

## 快速开始
\`\`\`bash
python main.py
